# MarketAnalys
An institutional-grade professional Telegram bot designed to perform technical analysis research, generate dynamic price charts, and deliver real-time market news using data from the Binance API and Marketaux API.
​🚀 Key Features
​Professional Multi-Indicator Analysis: Utilizes advanced indicators such as RSI (14), EMA (20/50), ATR (14), and Bollinger Bands (20, 2) on a 6-Hour Time Frame (TF 6H).
​Symmetrical Entry Setup & Risk Management: Provides objective Entry, Stop Loss (SL), and two Take Profit targets (TP1 & TP2) for both LONG and SHORT positions, complete with underlying rationales.
​Interactive Visual Charts: Generates professional candlestick charts with direct price-level overlay lines using matplotlib.
​Macroeconomic News Integration: Fetches the latest financial news relevant to the analyzed asset using the Marketaux API.
​Universal Binance Access: Supports analysis for all crypto coins, tokens, commodities, stocks, and ETFs actively listed on the Binance Spot Market.
